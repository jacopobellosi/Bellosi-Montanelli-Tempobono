\section{Requirements Traceability}

This section provides a comprehensive mapping between the functional requirements defined in the RASD and the specific sub-components described in the Low-Level Component View (Section 2.4) of the Design Document.

\subsection{Requirement Allocation}
The following list details the specific responsibilities of each low-level sub-component regarding the system requirements.

\begin{itemize}
    \item \textbf{User Service} (Backend / Auth Service)
    \begin{itemize}
        \item \textbf{R1, R3, R6:} Handles the business logic for registration, login, and logout.
    \end{itemize}

    \item \textbf{Hash Password \& Token Manager} (Backend / Auth Service)
    \begin{itemize}
        \item \textbf{R2:} Ensures credential uniqueness and security validation.
        \item \textbf{R4:} Provides the validation logic to trigger feedback on failed attempts.
    \end{itemize}

    \item \textbf{Profile Manager} (Backend)
    \begin{itemize}
        \item \textbf{R5:} Manages the retrieval and update of user personal information.
    \end{itemize}

    \item \textbf{Path Searcher} (Backend / Path Service)
    \begin{itemize}
        \item \textbf{R7, R25:} Handles geospatial searching while filtering by Path Visibility (R25).
    \end{itemize}

    \item \textbf{Path Merger} (Backend / Path Service)
    \begin{itemize}
        \item \textbf{R8, R9:} Retrieves raw reports and calculates the merged path status.
        \item \textbf{R10:} Computes the path score based on conditions and metrics.
    \end{itemize}

    \item \textbf{Detailed Path View} (Backend / Path Service)
    \begin{itemize}
        \item \textbf{R11, R12, R13:} Aggregates geometry, status, and reports for list and detailed views.
        \item \textbf{R14:} Fetches and attaches the weather forecast to the path view.
    \end{itemize}

    \item \textbf{Path Adding} (Backend / Path Service)
    \begin{itemize}
        \item \textbf{R36:} Handles the persistence of manually created path geometries.
        \item \textbf{R25:} Enforces the initial visibility setting during creation.
    \end{itemize}

    \item \textbf{Add Status/Obstacle to Path} (Backend / Path Service)
    \begin{itemize}
        \item \textbf{R37, R38:} Handles the persistence of manual status and obstacle reports.
    \end{itemize}

    \item \textbf{Trip Adding} (Backend / Trip Service)
    \begin{itemize}
        \item \textbf{R19, R33:} Manages the atomic saving of trips (including those from new registrations).
        \item \textbf{R26:} Enforces Trip Visibility logic during the save process.
        \item \textbf{R32:} Fetches and associates the historical weather snapshot.
    \end{itemize}

    \item \textbf{Trip Searcher} (Backend / Trip Service)
    \begin{itemize}
        \item \textbf{R34, R35:} Handles the retrieval of the user's trip history and details.
    \end{itemize}

    \item \textbf{Recording State Manager} (Client / Recording Service)
    \begin{itemize}
        \item \textbf{R20, R27:} Orchestrates the start/stop lifecycle of the recording.
    \end{itemize}

    \item \textbf{GPS Tracker \& Stats Tracker} (Client / Recording Service)
    \begin{itemize}
        \item \textbf{R21:} Captures and processes the GPS coordinate sequence.
        \item \textbf{R22, R31:} Calculates real-time and final statistics (using Elapsed Time).
    \end{itemize}

    \item \textbf{Sensor Processor} (Client / Recording Service)
    \begin{itemize}
        \item \textbf{R23, R24:} Monitors accelerometer/gyroscope data and logs events on threshold exceed.
    \end{itemize}

    \item \textbf{Local Storage \& UI Layer} (Client)
    \begin{itemize}
        \item \textbf{R28, R29:} Manages the local review queue and user confirmation logic.
        \item \textbf{R30:} Persists confirmed events as valid reports.
        \item \textbf{R39:} Provides the UI for visibility selection.
        \item \textbf{R40:} Displays feedback messages.
    \end{itemize}

    \item \textbf{Navigation Manager} (Client)
    \begin{itemize}
        \item \textbf{R15:} Triggers the external navigation service.
        \item \textbf{R16, R17, R18:} Manages the post-navigation summary and optional registration.
    \end{itemize}
\end{itemize}
